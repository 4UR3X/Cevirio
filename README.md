# Çevirio

Hızlı, çapraz platform (Windows / Linux / macOS) ekran çeviri aracı. Ekran yakalama, OCR ve overlay ile çalışır; oyun sürecine müdahale etmez.

## Durum
Erken geliştirme aşaması. Tasarım: [docs/TASARIM.md](docs/TASARIM.md)

## Geliştirme
Gereksinimler: Rust (stable), Node 20, Windows'ta MSVC Build Tools.

```
cd app/src-tauri
cargo run
```
